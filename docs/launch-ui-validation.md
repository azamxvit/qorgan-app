# Заставка Qorğan — 14 октября 2026

Согласованный объём: существующий фирменный знак, Manrope Qorğan, фон #F7F8F8, плавное появление и масштаб 0.94→1, переход к «Защите» за одну секунду. Другие функции не добавлены.

Знак без внешних зависимостей перенесён из `qorgan-web/src/app/icon.svg` в Flutter CustomPainter и Android vector drawable. HomeShell загружает данные под заставкой, уведомления убирают её перед открытием SMS. Возврат из фона не перезапускает анимацию. При disableAnimations сохраняется статичная заставка без движения и затухания.

- `aapt2 compile --dir android/app/src/main/res`: ресурсы компилируются.
- В живом Flutter web-превью 8788 проверены «Посмотреть запуск», фирменная заставка, переход к «Защите», «Повторить».

Android API31+ использует системную тему с тем же знаком и фоном. Дополнительная задержка системного экрана не задана. Подход соответствует [документации Android SplashScreen](https://developer.android.com/develop/ui/views/launch/splash-screen). Секунда относится к Flutter-анимации после первого кадра; время запуска процесса/движка зависит от телефона.

APK в этом шаге не пересобирался; нативный переход на телефоне пока не проверен. Проверка ресурсов не заменяет сборку APK.
