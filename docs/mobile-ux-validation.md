# Проверка нового UX Qorğan

Дата: 7 ноября 2026. Реализовано по [согласованному UX](superpowers/specs/2026-11-07-mobile-ux-design.md).

## Что реализовано

Приветствие с существующим логотипом, без аккаунта; отдельные шаги разрешений и явное включение защиты; три постоянных раздела; ручная проверка с сохранением черновика в сеансе; единое представление риска и причин; история с четырьмя фильтрами; настройки, локальная информация о данных и подтверждённая очистка истории.

Значения `QorganColors` не изменены. Все новые экраны используют существующую палитру и Manrope. Подозрительные результаты выделены существующим тёмным токеном, промежуточные — светло-мятным, низкий риск — нейтральным. Есть текст и символы, смысл не зависит только от цвета.

## Автоматические проверки

- `flutter test --no-pub --reporter expanded`: **163 теста прошли**.
- `flutter analyze --no-pub`: **No issues found**.
- `dart format --output=none --set-exit-if-changed lib test`: **74 файла, 0 изменений**.
- `git diff --check`: без ошибок.
- `git diff -- lib/ui/core/colors.dart`: пустой diff.

Проверены первый запуск и повторный вход, миграция сохранённого выключенного состояния, отказ в разрешениях, ошибки состояния и истории, сохранение текста между вкладками, асинхронная проверка при изменении текста и смене маршрута, разные уровни риска, переходы по уведомлению, удалённые сообщения, подтверждение очистки, приходы во время очистки, предупреждения для вытесненных записей и отложенная публикация предупреждения после удаления записи.

Отдельная проверка кода нашла три ошибки порядка асинхронных событий; все исправлены и покрыты воспроизводящими тестами. Завершившееся включение защиты не закрывает новое сообщение, открытое поверх настройки. Очистка отменяет конкретные старые предупреждения и сохраняет новые; успешно сохранённое, но затем удалённое сообщение не оставляет позднее предупреждение.

## Что требует Android SDK и устройства

Команда `flutter build apk --release --no-pub` остановилась до сборки: **No Android SDK found**. SDK по прежнему пути из `android/local.properties` отсутствует; `adb` и устройство недоступны. Новый APK не создан. Нативные изменения MainActivity, реальные системные диалоги и доставка уведомлений на устройстве в этой сессии не проверены.

После восстановления SDK необходимо собрать APK и пройти [проверку телефона](android-phone-check.md), включая отказ/повторную выдачу разрешений, возврат из Android Settings, запуск по уведомлению, очистку истории и работу после ухода приложения в фон. Старые отчёты Android относятся к предыдущему интерфейсу.
