# Qorğan — мобильное приложение

Flutter. Две фичи на телефоне: ручная проверка текста SMS и предупреждения о подозрительных входящих SMS на Android. SMS не удаляются, ссылки не блокируются. Решение считается на устройстве и не открывает модули сайта.

Сайт остаётся порталом дипфейка и проверки документов.

Слои как в [руководстве Flutter](https://docs.flutter.dev/app-architecture/guide): экраны и view model в `lib/ui`, правило в `lib/domain`, репозиторий и сервис входящих SMS в `lib/data`.

## Запуск

```bash
flutter pub get
flutter run
```

Android: API 24+, Java 17, Android SDK 36 и NDK 28.2.13676358. Сборка: `flutter build apk --release`. Тестовая release-сборка использует debug-подпись из Android-шаблона; ключ для публикации настраивается отдельно.

При первом запуске защита выключена. На вкладке «Фон» нажмите «Включить защиту» и разрешите приём SMS и уведомления. Последние 100 принятых сообщений и переключатель сохраняются локально; Android backup отключён. Текст SMS не появляется в предупреждении на экране блокировки.

Приём реализован локальной MIT-версией `another_telephony`, сокращённой до входящих SMS. Приёмник использует `goAsync()` и ждёт завершения Dart-обработчика до девяти секунд; обработчик вызывает то же `inspectMessage`, что и ручная проверка. Постоянного foreground service и сетевого анализа нет. Лицензии: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md), а также кнопка «Лицензии open source» в приложении.

Проверки: `flutter analyze`, `flutter test`. Порядок проверки APK на телефоне: [docs/android-phone-check.md](docs/android-phone-check.md). Свайп из недавних проверяется отдельно от системной «Принудительной остановки»: после force-stop требуется вручную открыть приложение. Очень медленный запуск движка, энергосбережение производителя и отзыв разрешений могут мешать предупреждению; проверка на реальном устройстве обязательна.

Результаты проверки release APK: [docs/android-validation.md](docs/android-validation.md).

## Светлый интерфейс

Четыре экрана Flutter: «Защита», карточка SMS, «Признаки» и «Сообщения». Тема Manrope; шрифт встроен и не загружается из сети. Статистика основана на последних 100 сохранённых SMS. Настройки защиты и лицензии доступны через аватар; ручная проверка — через меню из четырёх точек или список сообщений.

Превью тех же компонентов с демонстрационными SMS:

```bash
flutter run -d web-server --web-port 8788 --dart-define=QORGAN_PREVIEW=true
```

Снимок четырёх экранов: `artifacts/qorgan-light-preview.png`. Для повторного рендера: `flutter test test/design_preview_test.dart`. Manrope распространяется по OFL; лицензия находится в `assets/fonts/OFL.txt` и зарегистрирована в экране лицензий приложения.

### Заставка Qorğan

При обычном запуске фирменный знак сайта и название плавно появляются на светлом фоне. Анимация длится одну секунду; состояние защиты и история загружаются параллельно. При возвращении из фона она не повторяется, а при открытии SMS из уведомления скрывается сразу после получения выбранного сообщения. Системная настройка уменьшения анимации отключает движение и прозрачность.

В галерее Flutter на `http://127.0.0.1:8788/` нажмите «Посмотреть запуск». Кнопка «Повторить» позволяет снова проиграть заставку и переход к главному экрану. Снимок: `artifacts/qorgan-launch-preview.png`.
