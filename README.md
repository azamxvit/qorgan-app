# Qorğan — мобильное приложение

Flutter. Две фичи на телефоне: ручная проверка текста SMS и предупреждения о подозрительных входящих SMS на Android. SMS не удаляются, ссылки не блокируются. Решение считается на устройстве и не открывает модули сайта.

Сайт остаётся порталом дипфейка и проверки документов.

Слои как в [руководстве Flutter](https://docs.flutter.dev/app-architecture/guide): экраны и view model в `lib/ui`, правило в `lib/domain`, репозиторий и сервис входящих SMS в `lib/data`.

## Запуск

```bash
flutter pub get
flutter run
```

Android: API 24+, Java 17, Android SDK 36 и NDK 28.2.13676358. Для разработки: `flutter run`. Подписанный релиз: `python3 scripts/build_play_release.py --apk`; без приватного upload-ключа release-сборка завершается ошибкой. Подготовка AAB, подпись и CI: [инструкция Google Play](docs/google-play/build-and-upload.md).

При первом запуске появляется приветствие с логотипом. Аккаунт не нужен: можно сразу проверить текст SMS или выбрать «Настроить защиту». Доступ к новым SMS и уведомлениям запрашивается отдельно; после выдачи разрешений нажмите «Включить защиту». Последние 100 принятых сообщений и переключатель сохраняются локально; Android backup отключён. Текст SMS не появляется в предупреждении на экране блокировки.

Кроме словарей правило сверяет адреса из сообщения с блоклистом фишинговых хостов: снапшот зашит в сборку, дальше обновляется по сети только на переднем плане, с интервалом не менее 12 часов после успешного обновления. Неудачная попытка может повториться при следующем запуске. Это единственная причина разрешения `INTERNET` — текст сообщений и отправитель в запросе не передаются. Хостинг списка получает сетевой IP и ведёт технические журналы; подробности раскрыты в политике. Устройство и лицензия данных: [docs/blocklist.md](docs/blocklist.md).

Приём реализован локальной MIT-версией `another_telephony`, сокращённой до входящих SMS. Приёмник использует `goAsync()` и ждёт завершения Dart-обработчика до девяти секунд; обработчик вызывает то же `inspectMessage`, что и ручная проверка. Постоянного foreground service и сетевого анализа нет. Лицензии: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md), а также кнопка «Лицензии open source» в приложении.

Проверки: `flutter analyze`, `flutter test`. Прогон печатает строку `detector: precision … recall …` — это шлюз правила на корпусе `test/domain/sms_corpus.dart`; ложные тревоги на легитимных SMS запрещены полностью (`minPrecision = 1.0`). Те же команды выполняет CI: [.github/workflows/checks.yml](.github/workflows/checks.yml). Порядок проверки APK на телефоне: [docs/android-phone-check.md](docs/android-phone-check.md). Свайп из недавних проверяется отдельно от системной «Принудительной остановки»: после force-stop требуется вручную открыть приложение. Очень медленный запуск движка, энергосбережение производителя и отзыв разрешений могут мешать предупреждению; проверка на реальном устройстве обязательна.

Результаты предыдущей проверки release APK (до нового UX): [docs/android-validation.md](docs/android-validation.md).

## Светлый интерфейс

Три постоянных раздела: «Защита», «Проверить SMS», «Сообщения». Настройки и лицензии открываются через шестерёнку. Ручная проверка выполняется по кнопке «Проверить»; черновик сохраняется при переключении вкладок, результат не добавляется в историю. История входящих SMS различает три уровня: «Низкий риск», «Стоит проверить», «Подозрительное SMS». Подробности показывают реальные признаки и баллы правила.

Цветовые значения `QorganColors` сохранены. Тема Manrope; шрифт встроен и не загружается из сети. Статистика основана на последних 100 сохранённых SMS. Очистка истории в настройках удаляет только данные Qorğan и не выключает защиту.

Описание UX: [согласованная спецификация](docs/superpowers/specs/2026-11-07-mobile-ux-design.md). Проверки и превью: [mobile-ux-validation](docs/mobile-ux-validation.md).

Демонстрационных сообщений в приложении нет: список заполняется только теми SMS, которые пришли на телефон. Текст примеров живёт в `test/domain/sms_corpus.dart` и в сборку не попадает — это проверяет `test/no_demo_data_test.dart`.

Manrope распространяется по OFL; лицензия находится в `assets/fonts/OFL.txt` и зарегистрирована в экране лицензий приложения.

### Заставка Qorğan

При обычном запуске фирменный знак сайта и название плавно появляются на светлом фоне. Анимация длится одну секунду; состояние защиты и история загружаются параллельно. При возвращении из фона она не повторяется, а при открытии SMS из уведомления скрывается сразу после получения выбранного сообщения. Системная настройка уменьшения анимации отключает движение и прозрачность.

Снимок заставки: `artifacts/qorgan-launch-preview.png`, перерисовывается через `flutter test test/launch_test.dart`.
