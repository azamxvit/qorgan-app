# Qorğan — мобильное приложение

Фоновая защита, проверка банковских сообщений и экран AI Analyze для дипфейков.

Сейчас фон и проверка текста работают как прототип на правилах. Модель дипфейка подключим после обучения: до этого приложение не показывает ложный вердикт.

## Запуск

```bash
npm install
npx expo start
```

Дальше откройте проект в Expo Go на телефоне.
